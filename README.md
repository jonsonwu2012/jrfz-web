## 仓库结构

```
├── index.html                 交互网站入口（hash 路由：#/products、#/solutions …）
├── app.js / data.js / styles.css
├── clients.js                 合作酒店数据（宣传册客户名录、国际品牌、代表酒店），增删客户只改此文件
├── design-gallery.html        设计总览
├── image-audit-v2.html        39 张 V2 图片逐项核对
├── image-manifest-v2.json     图片映射与生成提示词
├── assets/                    网站图片（WebP，46 张）；assets/logos/ 为 12 个酒店品牌单色矢量标志
├── concepts/                  V1 版式概念图（WebP）
├── previews/                  浏览器渲染预览截图
├── *.md                       设计方案、生成提示词、设计系统、配色研究（源文件）
├── *.html（同名）             由 scripts/build_docs.py 从 .md 生成的文档网页
├── 404.html                   未找到页；旧的 xxx.md 地址自动跳转到 xxx.html
├── scripts/build_docs.py      Markdown → HTML 文档渲染脚本（需 pip install markdown）
├── .nojekyll
└── .github/workflows/pages.yml  部署时重新生成文档页，网站不直接发布 .md
```

## 部署说明

- 原始 PNG（共约 123MB）已无损尺寸转为 WebP（约 10MB），引用已同步修改，画面尺寸不变。
- 原始交付压缩包（约 137MB）超过 GitHub 单文件 100MB 限制，未纳入仓库，请另行保存。
- 修改任何 .md 文档后，推送即可；部署流程会自动重新生成对应的 HTML 页面。本地预览前可运行 `python3 scripts/build_docs.py`。
- 本地预览：在仓库根目录运行 `python3 -m http.server 8767`，访问 http://127.0.0.1:8767/ 。

## V2 更新内容

- 研究 2025–2026 配色方向并提供十色浏览入口：本白、沙色、摩卡棕、鼠尾草绿、橄榄绿、雾蓝、海军蓝、陶土色、酒红、暖灰。详细来源与适用边界见《配色趋势与图片核对-V2.md》。
- 每个产品子项独立生成图像，取消从分类封面继承产品图的逻辑；分类封面和三种酒店场景均独立生成。共39张新增图。
- 产品中心支持类别、材质、配色、关键词组合筛选；详情明确图示颜色，加入清单时携带颜色。芯类保持本白。
- 打开 image-audit-v2.html 逐项核对名称、颜色与图片；image-manifest-v2.json 保存每张图的完整生成提示词。本轮使用内置 image_gen 生成。
- 同一产品在列表、详情和询价缩略图使用同一资产，保持产品身份；不同产品、不同分类、不同场景资产互不混用。
- V1 概念图与旧预览保留作版式历史参考，V2交互稿与图片核对页为最新内容。
