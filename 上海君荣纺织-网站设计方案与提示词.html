B2B 酒店布草网站设计方案与提示词

版本：V1.0｜日期：2026-11-02（美国洛杉矶）｜状态：设计提案，待企业评审

1. 项目目标

为上海君荣纺织品有限公司设计一套时尚、高端、专业的 B2B 酒店布草网站。以酒店业主、采购负责人、客房运营、民宿经营者和项目采购团队为主要使用者。网站帮助访客完成：认识品牌 → 找到产品 → 理解规格 → 选择配套 → 整理询价需求。

核心转化不是零售购物，而是有效询盘、样品需求及项目配套沟通。首页兼顾形象、产品与采购入口。文案以简洁、准确、可信为原则。

已确认事实只有公司名称、B2B 销售定位及用户要求的酒店布草全品类网站方向。公司成立时间、工厂、产能、实际 SKU、资质、客户、业务范围、联系方式和服务承诺，均需要企业提供资料后确认。

3. 创意主题与品牌表达

主题：织就舒适，款待每一位宾客。

关键词：现代酒店美学、织物触感、安静的高级感、编辑式排版、清晰采购。

主文案：

从一间客房，到整座酒店。
为酒店与民宿采购提供全品类布草选型与配套。

英文辅助文案：Considered textiles. Exceptional stays.

JUNRONG / 君荣纺织仅作为本轮字标方案，不视为已确认商标或官方英文名称。

视觉规则：

  • 暖纸白 #F7F5EF：页面主底色。
  • 炭黑 #252923：正文、标题、页尾深色横幅。
  • 橄榄绿 #626A4B：主按钮、选中状态、场景方案区。
  • 砂色 #E8E3D8：询价清单和辅助区。
  • 灰绿分隔线 #DAD8CE：细线结构，少量使用。
  • 中文宋体式衬线标题，中文无衬线正文；拉丁字标用高对比衬线字体。
  • 桌面主标题约 58–68px、模块标题 38–44px、正文 15–17px；手机主标题约 36–40px。
  • 直角按钮与图片，细分隔线，大留白，避免悬浮圆角卡片、促销贴纸、跑马灯和密集弹窗。
  • 酒店床景、棉织物褶皱、毛巾毛圈、餐桌垂坠作为视觉重点，石材和木色仅作背景。
  • 摄影自然呈现，禁止为了统一颜色给所有图片叠加浓重色罩。
  • 140–220ms 控件过渡、轻微图片放大；遵循减少动画偏好。

5. 站点页面与导航

主导航：首页 / 产品中心 / 配套方案 / 定制服务 / 关于君荣。右侧：询价清单（数量） / 获取报价。

完整设计覆盖：

  1. 首页：品牌表达、六大品类、空间方案、协作流程、询价入口。
  2. 产品中心：分类、关键词搜索、材质筛选、结果数量和无结果状态。
  3. 产品详情模板：图片、选型说明、规格、数量、样品与询价动作、洗护建议。
  4. 配套方案：商务酒店、精品民宿、高端酒店三个场景。
  5. 定制服务：尺寸、材质、品牌色彩及项目配套的沟通路径。
  6. 关于君荣：确认的企业定位、品牌理念、后续真实资料呈现方式。
  7. 询价页面：选型清单、数量编辑、项目需求表与本地询价单。

后续资料齐全后可增加真实客户案例、资料下载、联系我们等页面。联系方式未提供时不生成虚假号码、地图或微信二维码。

6. 首页布局

6.1 页头

暖白背景、细底线、固定导航。左侧 JUNRONG / 君荣纺织及公司全称。中间五项主导航。右侧询价清单与主按钮。手机压缩为字标、询价数量和菜单按钮。

6.2 第一屏

桌面采用左 44% 文案、右 56% 摄影。左侧大标题“织就舒适，款待每一位宾客。”、两行说明、主按钮“探索全品类”、次入口“获取项目方案”。底部英文落款。右侧白色酒店床品、暖木色床头与柔和自然光，不叠加文字遮住产品。

手机先展示主文案和行动入口，再展示酒店床景。标题不拆出孤立标点。

6.3 品类索引带

客房床品 / BED LINEN；卫浴织物 / BATH LINEN；餐饮与空间 / TABLE & INTERIOR。链接进入对应分类。

6.4 全品类摄影区

标题“一站配齐，酒店每一处柔软。”。首行三图大小有变化，第二行三图等分。每个入口展示序号、中文名称、细分类摘要与箭头。图片直接贴版，不加悬浮卡片外壳。

6.5 空间配套区

左侧酒店空间摄影，右侧橄榄绿文本区。标题“让布草，成为空间的一部分。”。切换商务酒店、精品民宿、高端酒店，更新相关说明与场景。照片明确为概念图，不能冒充服务案例。

6.6 四步协作区

沟通需求 → 确认选型 → 样品评估 → 订单交付。采用四列大数字与短说明。具体流程以企业实际服务能力确认。

6.7 项目询价与页尾

深炭色横幅：为下一个项目，找到合适的布草。按钮：开始项目询价。页尾展示公司名称、产品与询价入口；正式联系方式、备案与隐私文件待提供后接入。

7. B2B 核心交互

产品中心

  • 桌面左分类右图册，手机分类横向滚动。
  • 搜索名称、分类关键词和材质方向，显示结果数量。
  • 无结果时有说明与“清除筛选”。
  • 示范目录展示 30 个选型条目，图片按系列复用，均为设计数据。

详情页

  • 左图右规格，手机上下排列。
  • 可选床型或产品规格、填写正整数数量。
  • 主按钮“加入询价清单”；次按钮“申请样品”。
  • “申请样品”只加入样品需求并进入询价，不承诺免费、不生成真实发货。
  • 规格表将材质、织造、尺寸、重量、起订量、交期等分开，未知项使用明确的待确认状态。
  • 不显示“立即购买”、虚构售价、折扣、库存和销量。

询价页

  • 合并同产品、同规格、同意向的条目；不同规格分别保留。
  • 支持修改数量与删除条目；空清单也可提交项目需求。
  • 表单：公司/酒店名称、联系人、联系电话、项目类型、预计客房数、计划交付时间、补充需求。
  • 房间数与计划时间可以选填，避免初次咨询负担过重。
  • 演示版仅生成本地 Markdown 询价单；明确未发送给企业。
  • 产品选择可保存在本机；联系人和电话不持久化、不传输。
  • 正式上线时再设计真实提交接口、接收端、隐私告知、去重与反垃圾措施。

8. 视觉与移动适配验收

  • 至少核对 1440px 桌面、768px 平板及 390px 手机布局；交付记录写明实际测试尺寸。
  • 首屏标题、按钮、导航和图片不得互相覆盖；无横向溢出。
  • 产品图比例稳定，图片加载时尽量保留空间。
  • 输入框有可见标签，键盘焦点明确，移动触控区域至少 44px。
  • 颜色信息不能单独表示选中；用边线、文本及可访问状态共同表达。
  • 图片有替代文字；尽量使用语义化导航、标题、表单和按钮。
  • 标题、CTA、分类及数量在所有页面保持一致。
  • 不将生成的整张 UI 图片作为实际网页；文字、按钮、表单均用原生代码实现。

七、目录与详情
目录：桌面左侧分类、右侧关键词搜索和材质筛选、三列摄影产品列表。移动端分类可横向滚动、产品两列。搜索必须有真实结果和空状态。
详情：左图右参数，说明产品定位，区分材质、组织、尺寸、重量、单位、工艺和供应条件。
可选择规格、填写正整数采购数量。“加入询价清单”实际更新全站条目数；“申请样品”加入样品需求，不表示已发货。

详情有产品说明、规格与定制、洗涤建议三个内容切换。
没有零售价格、加入购物车、立即购买、促销倒计时。

八、配套与定制
商务酒店关注规格统一和日常运营；精品民宿关注空间色彩和床型；高端酒店关注全空间织物与细节。
场景切换后更新说明、图片和建议系列。发起项目询价时带入场景名称与需求摘要。
定制页围绕尺寸、材质、品牌色彩和项目配套解释沟通流程。未确认的定制能力用提案状态呈现。

九、询价流程
桌面左需求表右选型清单，手机先看清单再填表。
字段包括公司/酒店名称、联系人、电话、项目类型、预计客房数、计划交付时间、补充需求；前 3 项必填，其余按实际情况设置。
支持数量修改、条目删除、空清单直接咨询、输入校验和修改后重新生成。
设计演示阶段仅生成并下载本地询价单 Markdown，明确提示“尚未发送给企业”，不假装提交成功。
联系人、电话不保存到 localStorage，不向第三方发送；产品选择可以保存在本机。
